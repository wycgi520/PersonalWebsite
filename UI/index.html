我是谁，在做什么

我是国易，一个写了七年代码的全栈工程师。职业生涯大部分时间在做内容驱动的产品——CMS、权限系统、搜索与推荐，这类东西前端要好用，后端要扛得住，数据模型一开始就不能将就。

技术上我偏实用主义：Next.js 做端到端，Hono 处理需要独立伸缩的 API，Prisma + PostgreSQL 管数据。该上 Redis 和队列的地方上，不该上的地方绝不提前抽象。

工作之外我在写技术文章，维护一个自己用的工具箱，偶尔做点动效实验。这个网站本身就是其中一个。
