
## 前端与界面
- TypeScript + React：使用组件化方式构建网页界面。
- Next.js：结合 React、SSR、SSG 和 App Router 构建 SEO 友好的全栈网站。
- Tailwind CSS：使用原子化 CSS 快速实现响应式页面样式。
- shadcn/ui：结合 Tailwind CSS 构建可定制的组件库。
- Ant Design：使用成熟的 UI 组件快速完成后台或管理界面。
- Motion + Magic UI：为页面添加动画、交互效果和 Landing Page 视觉效果。
- Markdown + MDX：结合自定义渲染器实现文章展示、代码高亮、目录锚点和组件嵌入。
- React Hook Form + Zod：实现表单管理、字段校验和异步验证。
- Zustand：实现主题切换、用户配置和跨组件状态管理。
- React Hooks：使用 useState、useEffect、useMemo、useCallback 等实现组件逻辑复用。
- Artplayer：封装网页视频播放器。
## 后端与全栈开发
- Next.js Server Actions：结合 Prisma 实现轻量级全栈应用和服务端数据操作。
- Hono.js：构建轻量、高性能的后端 API 服务。
- Hono + OpenAPI：结合 Swagger、Scalar、Apifox 等工具实现接口文档、调试和类型安全。
- Prisma + PostgreSQL：实现数据库建模、ORM 操作、分页查询和关联数据管理。
- NestJS：用于构建大型、结构化的 Node.js + TypeScript 后端应用。
- Laravel：使用 PHP MVC 框架开发传统 Web 应用和后端 API。
- Node.js：作为 JavaScript/TypeScript 服务端运行环境。
## 用户系统与安全
- Better Auth：结合 Hono 和 Next.js 实现用户注册、登录、Cookie Session 和资源保护。
- JWT + JWKS：使用非对称密钥实现 API 身份认证和远程验签。
- OAuth2 + Google Login：实现 Google 第三方登录。
- CASL + RBAC：结合数据库角色和权限模型实现动态权限控制。
- Hono Middleware：实现认证、鉴权和权限上下文注入。
## 数据与异步任务
- Redis：实现验证码发送频率控制、缓存和临时数据存储。
- BullMQ + Redis：实现异步邮件发送和后台任务队列。
- Nodemailer + SMTP：实现注册验证、密码找回等邮件发送。
- 腾讯云 SDK + 阿里云 SDK：接入云服务完成邮件或短信相关功能。
- Day.js：实现日期格式化和时间处理。
## 搜索与内容系统
- MeiliSearch：结合文章标题、摘要、正文、分类和标签实现全文搜索。
- Prisma 关联模型：实现文章、分类、标签之间的一对多、多对多和无限级嵌套关系。
- Markdown/MDX 编辑器：实现支持实时预览和自定义渲染的内容编辑功能。
## 工程化与开发工具
- Turbopack：作为 Next.js 项目的快速开发和构建工具。
- pnpm：管理项目依赖和执行开发脚本。
- clsx：动态组合 React CSS 类名。
- Lodash：提供常用 JavaScript 工具函数。
- Immer：结合 Proxy 简化不可变数据更新。
- Rimraf：跨平台清理构建目录。
- Micromatch：实现文件路径和 Glob 模式匹配。
- utility-types：补充 TypeScript 高阶类型工具。
- react-use：复用常见 React Hooks。
- DBeaver：可视化管理和调试数据库。
## 渲染与网络协议
- SSR：结合 Next.js 服务端渲染页面，提升首屏速度和 SEO。
- SSG：预生成静态页面，适合博客、文档和内容型网站。
- CSR + SPA：结合 React 在客户端实现高交互单页应用。
- RESTful API：结合 Hono 和 OpenAPI 设计标准化接口。
- JWT：使用 Bearer Token 进行 API 身份认证。
- OAuth2：实现第三方账号授权登录。
- SMTP：实现系统邮件发送。
