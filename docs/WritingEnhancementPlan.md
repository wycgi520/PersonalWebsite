# 写作板块详情页与互动优化方案

日期：2026-10-21。状态：六篇正文已核对发布。生产库与运行时密钥在发布前完成初始化；站长账号、备份定时器与恢复演练随本次上线执行。

## 目标与已确认选择

完成“文章列表 → 详情阅读 → 点赞 → 相邻文章 → 评论”的闭环，保留中英双语、深浅主题与动态效果偏好。

- 正文在 Git 仓库中使用 Markdown；不建设在线文章后台。
- PostgreSQL + Prisma 保存共享点赞、评论和审核记录。
- 访客免登录，以昵称发表评论；默认审核后公开。
- Better Auth 管理站长会话，关闭公开注册，提供简易评论审核页。
- 原有六篇摘要迁移为草稿，不编造个人经历或技术测量结果。

## 内容与阅读体验

- 详情地址为 `/{locale}/writing/{slug}`；slug 沿用原有文章 ID。
- 内容路径为 `content/writing/<slug>/<zh|en>.md`，frontmatter 包含 `title`、`summary`、`category`、`date`、可选 `updated` 和必填布尔值 `draft`。日期需使用引号，格式为 `YYYY-MM-DD`。
- 发布要求 `draft: false` 且正文非空。列表、归档、sitemap 只包含当前语言已发布版本；缺少译文时显示提示和已发布原文入口；未知或全草稿 slug 返回 404。
- 支持标题、列表、引用、图片、表格和代码高亮；不执行 MDX，不启用原始 HTML，过滤不安全链接协议。
- 正文最大约 760px。桌面右侧吸顶目录，移动端上方折叠目录，提取二、三级标题并生成稳定、可去重的锚点。
- 顶部与固定阅读工具均可返回写作；超过一屏提供回到顶部，遵守减少动态效果偏好。移动工具栏预留安全区，页面底部为工具栏留空。
- 从列表进入时以 `cat`、`from` 保留分类和来源文章，返回时按分类恢复并定位来源。直接访问默认返回写作列表。切换语言保留合法上下文。
- 上一篇为时间更近，下一篇为时间更早；同日按 slug 排序，使用当前语言全部已发布文章，不受分类限制；边界不显示不存在的链接。
- 每篇文章具备独立 metadata、canonical、实际语言版本 hreflang、分享信息及 Article JSON-LD。正文服务端渲染，互动异步请求，不让数据库依赖进入静态内容构建。

## 互动接口与规则

| 接口 | 行为 |
| --- | --- |
| `GET /api/writing/{slug}/reactions` | 点赞总数、当前访客状态、已公开评论数 |
| `PUT /api/writing/{slug}/like` | `{ liked: boolean }`，按目标状态幂等写入 |
| `GET /api/writing/{slug}/comments?cursor=...` | 仅公开评论，时间和 ID 升序，20 条游标分页 |
| `POST /api/writing/{slug}/comments` | `{ nickname, text }`，返回 202 和 PENDING |
| `PATCH /api/admin/comments/{id}` | 管理员设置 APPROVED、REJECTED 或 HIDDEN |
| `GET /api/health/writing` | 检查互动数据表可查询，不返回配置或错误详情 |

- 中英版本共用 slug 对应互动；签名的 HttpOnly、SameSite Cookie 识别匿名访客，生产环境启用 Secure。数据库复合主键保证每篇每访客最多一个赞。清 Cookie 或换设备无法保证按人去重。
- 昵称去空白后 1–30 字，正文 1–500 字，评论作为纯文本显示；请求正文最多 8 KiB。
- 写接口校验配置的同源 Origin，所有互动及管理 API 返回 `Cache-Control: no-store`。
- 评论每分钟 1 次、每小时 5 次，点赞每分钟 30 次；分别限制访客和 IP，计数存数据库并在事务中处理。只有配置 `TRUST_PROXY=1` 且前置代理覆盖 X-Real-IP 时信任该头；未配置时使用保守的共享 IP 桶。
- 失败保留评论输入，点赞失败回滚，服务不可用显示重试。评论成功只提示待审核，不伪装成已公开。
- 不导入旧预置点赞、评论和 localStorage；真实互动从零开始。

## 审核与发布

- 入口：`/zh/admin/login`、`/en/admin/login`；审核页 `/[locale]/admin/comments`。
- 公共注册关闭；通过服务器命令创建站长和重置密码，重置时撤销现有会话。
- 管理页及写 API 均检查服务端会话中的管理员身份。页面按待审核、已公开、已拒绝、已隐藏筛选，支持分页；审核人和时间独立记录。
- 使用现有 standalone 发布，增加 Prisma 生成、内容检查、测试及运维工具打包。
- 服务器迁移在原子切换版本前执行，迁移失败不切换；使用向后兼容迁移，代码回退不自动回退数据库。
- 数据库与运行时密钥不在 release 中；新增数据库健康检查、每日备份 timer、保留最近七份。具体初始化和恢复步骤见 `Deployment.md`。

## 验证与发布条件

- 自动化覆盖日期/元数据校验、草稿与缺失语言、排序边界、Markdown 安全与锚点、上下文参数。
- 数据库集成测试使用临时 PGlite PostgreSQL 兼容引擎及 Prisma，覆盖共享点赞、重复写入、待审核隔离、站长登录、审核记录、隐藏、限流和同源检查。它不能代替独立 PostgreSQL 生产环境的锁竞争、备份恢复及发布验证。
- 本地验收需覆盖 375px/平板/桌面、双语/双主题、键盘、减少动态效果、目录、长文返回、首尾邻接、404、缺失译文和数据库故障。
- 正式发布前补齐实际正文、配置 PostgreSQL 与密钥、初始化站长、执行备份恢复演练，并在服务器验证迁移及版本回退。临时测试内容不提交为正式文章。
- 不包含 Newsletter 后端、全文搜索、在线正文编辑、评论通知、嵌套回复或访客账号系统。
